Paper Research Agent
The user inputs a research question, for example:
"Investigate methods for improving the retrieval quality of RAG since 2024, comparing HyDE, Reranker and Query Rewrite."
The Agent automatically completes:
1. Decomposing the research task
2. Searching for relevant papers
3. Obtaining abstracts or parsing PDFs
4. Extracting methods, datasets and experimental conclusions
5. Comparing different papers
6. Generating a Markdown research report with source citations
7. Saving the research record and supporting further inquiries
This project is suitable for AI students as it can simultaneously demonstrate LLM, RAG, tool invocation, planning, structured output, memory and evaluation, and is relevant to your future course learning, research and job hunting.
